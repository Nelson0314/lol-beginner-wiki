## 角色類型（S6）
| 類型 | 擅長 | 弱點 | 範例（S11 英雄標籤） |
|------|------|------|------|
| **坦克**（Tank） | 承受傷害、干擾敵人、開團 | 輸出低 | 墨菲特、雷歐娜 |
| **鬥士**（Fighter） | 耐打的近戰持續輸出 | 射程短 | 蓋倫、沃維克 |
| **法師**（Mage） | 用技能造成大量傷害 | 被近身後脆弱 | 拉克絲、安妮 |
| **射手**（Marksman） | 遠距離普通攻擊的穩定輸出 | 非常脆弱，依賴裝備 | 艾希、凱特琳 |
| **刺客**（Assassin） | 快速切入擊殺單一目標 | 脆弱 | 阿璃 |
| **控制者**（Controller） | 保護隊友、**控場**（限制敵人行動） | 本身傷害低 | 索拉卡（遊戲標籤為 Support） |

## 陣容搭配（S6）
- 各類型互有強弱，沒有一類全面壓制，所以一隊要混合不同類型。
- 新手可用的簡單檢查：隊上至少有一位能承受傷害的（坦克或鬥士）、有主要輸出（射手、法師）、有控場能力。（本 Wiki 依 S6 各類型的職能歸納，非來源原文；此三分法為 ① 討論時確定的教學框架）
- 各位置常見類型：上路 鬥士／坦克；打野 鬥士／刺客／坦克；中路 法師／刺客；下路 射手；輔助 控制者／坦克。

## 新手推薦英雄（建議，S9；譯名依 S11）
挑選標準：需要瞄準的技能（skillshot）少、容錯高、任務明確。

| 位置 | 推薦 |
|------|------|
| 上路 | 蓋倫（Garen）、墨菲特（Malphite） |
| 打野 | 沃維克（Warwick）、阿姆姆（Amumu） |
| 中路 | 安妮（Annie）、拉克絲（Lux） |
| 下路 | 艾希（Ashe）、好運姐（Miss Fortune）、凱特琳（Caitlyn） |
| 輔助 | 雷歐娜（Leona）、索拉卡（Soraka）、納帝魯斯（Nautilus） |
